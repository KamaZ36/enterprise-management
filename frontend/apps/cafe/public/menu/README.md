# Фото блюд для витрины кафе

Кабинет кафе берёт фото в таком порядке:

1. ссылка `image_url` из карточки номенклатуры (заполняется в админке:
   «Справочники» → «Номенклатура» → «Изменить» → «Фото для меню»);
2. файл в этой папке по артикулу: `<SKU>.jpg` (например `BEEF-SHOULDER.jpg`);
3. если ничего не нашлось — заглушка с первой буквой названия.

Файлы из `public/` отдаются как `/menu/<SKU>.jpg`, сборка их копирует как есть.
